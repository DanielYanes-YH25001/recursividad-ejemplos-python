# Ejemplos de Recursividad en Python 🐍

Este repositorio contiene ejemplos prácticos de **recursividad** en Python, como:

- Suma de una lista de números.
- Invertir cadena.
- Serie de Fibonacci.
- Cálculo del MCD con el Algoritmo Euclidiano.
- Otros interesantes ejemplos.

## ¿Cómo probar los ejemplos?

1. Clona este repositorio utilizando https o ssh si se tiene configurado:

```bash
# HTTPS
git clone https://github.com/DanielYanes-YH25001/recursividad-ejemplos-python.git

# SSH
git clone git@github.com:DanielYanes-YH25001/recursividad-ejemplos-python.git
````

2. Entra en la carpeta:

```bash
cd recursividad-ejemplos-python/
```

3. Ejecuta cualquier ejemplo:

```bash
python 1_suma_lista_numerica.py
```

## Versión de Python

Compatible con **Python 3.8 o superior**.

## ¿Cómo contribuir?

Puedes contribuir de varias formas:

### 🐛 Reportar problemas o sugerir mejoras

* Abre un **Issue** describiendo el problema o tu propuesta.
* Intenta ser claro e incluir ejemplos si es posible.

### 💻 Contribuir con código

1. Haz un fork del repositorio
2. Crea una rama (`git switch -c nueva-funcionalidad`)
3. Realiza tus cambios
4. Haz commit (`git commit -m "Agrega nuevo ejemplo de recursividad"`)
5. Sube los cambios (`git push origin nueva-funcionalidad`)
6. Abre una Pull Request
